#### Challenges
One challenge I had was making sure that the text sizes and words look good on all screen sizes. For example a heading that looks good on a big desktop screen can be very big on a mobile phone or tablet, and it won't look as good as it's supposed to. So I used a media query which makes the text be a specific size on a specific screen size. 
``` CSS
@media (max-width: 768px) {
    .main-title {
        font-size: 40px;
    }
}

@media (max-width: 480px) {
    .main-title {
        font-size: 30px;
    }
}
```
I used this media query for my Medical Practice title. Originally I didn't put a media query for it but after I finished my MVP I decided why not search up my website on my phone and see it from other perspective. The first thing I noticed was how big the title was, so I went into my IDE and added the media query to make the text sizes smaller on a smaller screen size.
